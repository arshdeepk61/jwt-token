# JWT Token Service

A Spring Boot service for JWT token generation, validation, and management.

## Features

- JWT token generation and validation
- Token refresh mechanism
- User authentication
- Keycloak integration

## Prerequisites

- Java 11+
- Maven 3.6+
- Spring Boot 2.7+

## Building

```bash
mvn clean install
```

## Running

```bash
mvn spring-boot:run
```
